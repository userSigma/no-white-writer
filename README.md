# 不白写作

一个安静的本地写作工具：书架 → 卷 → 章，每章一个纯文本文件，退出自动保存。
Flutter 编写，v1 只发布 Windows x64，代码结构为 macOS ARM / Windows ARM / Linux / Android 预留。

## 现在能做什么（0.4.0 / M1）

- **主题**：保留 0.2 的朱砂强调色、彩色书脊、字体和 Fluent 控件样式；浅色内容底色纯白、深色内容底色纯黑。
- **书架**：卡片固定 220×300 逻辑像素；按最近编辑或书名排序，Enter 直接写作。右键、长按、卡片更多按钮或 `Shift+F10` 打开无框作品菜单，可编辑信息、导出本书、删除作品。
- **作品信息**：名称单行、最多 50 个用户可见字符；备注固定三行、内部滚动，兼容没有备注的旧作品；编辑不会切换当前作品绑定。
- **卷章目录**：无边框扁平卷头／章行，保留悬停、选中与键盘焦点反馈。`+` 直接创建「未命名章节」，卷名内联编辑；卷名、章名均可清空，灰色兜底名只用于显示，不写回原名。Enter/失焦保存、Esc 取消，组合输入不误提交。
- **侧栏**：左下返回书架、右下设置，均在目录底部且不随目录滚动；收起后侧栏及两按钮完全隐藏，顶栏仍可展开。200ms 可逆过渡、遵从减少动画设置。宽屏与每卷手动折叠并记忆；新建、选章、移动不自动开关，窄屏关闭目录后才聚焦新章标题。
- **独立编号**：每卷默认关闭，在「卷设置」启用；可改前后缀、阿拉伯/中文数字、补零位数、起始值和步长。编号按卷内顺序生成，列表、正文上方、窗口标题和单章导出文件名保持一致，不改原章名或正文。
- **拖放整理**：右键「移动」后仅握柄可拖动；同书跨卷移动章节、卷内排序和本书卷排序，支持边缘滚动、Tab/方向键及 Esc。折叠卷标题可接收章，不自动展开。
- **写作**：独立单行章节标题，与正文统一自动保存；霞鹜文楷 GB、字号/行距可调、回车自动缩进；`Ctrl+S` 立即保存。
- **自动保存与恢复**：停止输入 5 秒保存，失焦、切章、关窗先保存；原子临时写与备份恢复。跨卷移动另有持久恢复记录，校验正文及备份字节后更新归属，重启先恢复迁移；归属不明时停止而不重建覆盖。
- **删除与失败保护**：正文进入回收目录；删除、排序、移动与在途保存排他协调。失败保留草稿或可恢复文件，不通过强行清除输入法组词伪装保存成功。
- **设置**：就地向上／向下弹出菜单及子选单，不再切换设置页；主题、字号、行距、缩进、段间空行与导出目录可调，保存失败保留草稿并可重试。
- **导出**：章节菜单导出本章、卷菜单导出本卷、书架作品菜单导出本书，均为 UTF-8（无 BOM）TXT。本章仅正文；本卷／本书按当前顺序合并，以卷章显示名分隔，编号不写入正文。先保存并完整读取，坏 UTF-8、缺文件或未解决恢复记录会明确拒绝，不以空正文冒充成功；输出显示实际路径，重复导出不覆盖。
- **单实例**：再开一份只会提示「已经在运行」，不会碰磁盘。

M2 才做：查找替换、整库 zip 备份、专注模式、Inno Setup 安装包。

## 开发

```powershell
flutter pub get
flutter analyze
flutter test
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tool\fix_plugin_symlinks.ps1 # 本机 junction 修复，仅此进程的脚本策略
flutter build windows --release
```

构建产物是整个 `build\windows\x64\runner\Release\` 目录，**不能只复制其中的 exe**。
发布时将该目录的全部内容打成 ZIP，解压到普通用户目录后运行其中的 `no_white_writer.exe`。

```powershell
New-Item -ItemType Directory -Path build\packages -Force
$zip = 'build\packages\no-white-writer-0.4.0-windows-x64.zip'
if (Test-Path $zip) { throw '发布包已存在，请勿覆盖' }
Compress-Archive -Path build\windows\x64\runner\Release\* -DestinationPath $zip
```

本机旧沙箱生成的构建目录带有 Windows 低完整性标签，直接双击其中的程序会因无法写入 AppData 而无窗口。
应将完整 ZIP **解压到工作区外**（例如下载目录），不要在 ZIP 内直接运行或解压回旧构建目录；无需管理员权限，也不要降低数据目录权限。
详见 [环境记录 · 启动问题复测](docs/env.md#6-普通启动失败与发布包复测2026-10-26)。

数据默认在 `%APPDATA%\不白写作\`；`NWW_DATA_ROOT` 仅供隔离开发验收，不是正式启动问题的修复办法。
环境细节与实测数据见 [环境记录](docs/env.md)，设计规格见 [计划](PLAN.md)。
