# UI 评审 P2/P3 Implementation Plan

> **For agentic workers:** Use `executing-plans` to implement this plan inline. 用户已确认推荐方案；全程禁止子代理，不提交 Git。

**Goal:** 完成原 UI 评审全部 P2/P3，在保留既有 P0/P1、设置布局、保存/IME/焦点保护和旧作品数据的前提下统一视觉与默认体验。

**Architecture:** 沿用现有主题、书架、目录及设置边界。仅抽出一个共享的悬停操作可见性组件，统一鼠标/键盘/窄屏行为；章节默认仅在创建作品入口设置，不改变旧数据解析和作者标题。保留 Windows 原生标题栏，通过资源图标替换消除 Flutter 标识。

**Tech Stack:** Flutter 3.47 / Dart 3.13、fluent_ui 4.17、现有纯 Dart 控制器与文件存储；Pillow 仅用于本地生成多尺寸 Windows ICO，无新运行时依赖。

## 约束与已确认设计

- 内置强调色 #8C3A2B，纯白/纯黑背景不变；自定义主题颜色由用户配置控制。
- 书架标题“全部作品”，副标题“共 X 部作品 · 累计 Y 字”；每卡只出现一次作品名，去除副标题中的重复排序说明。
- 卷/章/作品菜单 28×28；鼠标悬停渐显，键盘进入区域显示，窄屏常显，右键/长按保留。
- 设置下拉文字靠左、箭头靠右，字号显示 px、行高显示倍数；主题与管理同排保持；书架设置入口为与相邻按钮同高的次级按钮。
- 封面严格 3:4，低强度常态阴影、悬停轻抬升，选择态不用粗强调色边框；固定卡片宽 220，高度为封面及元信息重新安排。
- 新作品启用全书汉字编号，空白章名仅显示“第一章”等；旧作品和显式阿拉伯数字规则不迁移、不批量改名。
- 设置右上关闭及保存失败守卫保留，完成改为普通描边 Button。
- Windows 仅更换图标，不新增自绘标题栏。
